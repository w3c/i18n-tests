Emphasis mark position in vertical Japanese text

Assertion

text-emphasis-position: over right; in a vertical-rl line the emphasis dot is drawn to the right of each character.

Instructions

This book contains one test. It passes if both of the following are true.

  1. The Japanese text below runs vertically, from top to bottom.
  2. A small filled dot is drawn to the right of each character of that text.

It fails if the text runs horizontally, if no dots are drawn at all, or if the dots are drawn anywhere other than to the right of the characters. If the reading system cannot lay text out vertically at all, record the result as not applicable.

Source code

.test {
  font-size: 1.5em;
  writing-mode: vertical-rl;
  text-emphasis: dot;
  }
<p class="test" xml:lang="ja" lang="ja">可能性を最大限に導き出すために</p>
