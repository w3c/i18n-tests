Emphasis mark position: under in horizontal Japanese text

Assertion

text-emphasis-position: under right; in a horizontal-tb line the emphasis dot is drawn below each character. The right component is ignored in horizontal writing mode.

This test uses a value other than the initial value (over right), so a reading system that ignores text-emphasis-position will draw the dots above the text and fail.

Instructions

This book contains one test. Check that the Japanese text below runs horizontally, from left to right. If it does not, record the result as blocked and note that horizontal layout is unavailable, so emphasis mark positioning cannot be assessed.

If the text runs horizontally, it passes if both of the following are true.

  1. The Japanese text below runs horizontally, from left to right.
  2. A small filled dot is drawn below each character of that text.

It fails if no dots are drawn at all, or if the dots are drawn above the characters or anywhere else. Record partial if dots are drawn below but are clipped, overlap the characters, or are missing for some characters; explain what you saw in notes.

Use the reading system's default settings where possible. If publisher styles are disabled, record blocked and note that the author CSS was not applied. If a font, theme, or font-size override changes the result, record it in notes. Use skipped only if you did not run the test.

Source code

.test {
  font-size: 1.5em;
  writing-mode: horizontal-tb;
  text-emphasis: dot;
  text-emphasis-position: under right;
  }
