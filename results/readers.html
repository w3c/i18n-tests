Reading systems: summarized test results

These tests check how far EPUB reading systems support the internationalization features covered by the browser test suite. Each test is a single EPUB file. Reading systems also apply their own stylesheets and user settings, so browser results are not a reliable guide to what a reading system does.

How to run the tests

If you have Node.js, build the test books with node tools/make-epubs.mjs; the EPUB files appear next to the test sources in readers/. Open each .epub file in the reading system and compare what you see with the pass criteria at the top of the book itself. Record a result for every test you ran.

How to add a result

Add an entry to readers/readers-data.js, under the identifier of the test you ran. Use the reading system's name in the reader field, its version, the operating system you ran it on, and one of the pass, fail, partial or skipped status values. A reading system only appears in the table once all of its results are in the file, so a newly tested reading system adds a column without any change to this page.
